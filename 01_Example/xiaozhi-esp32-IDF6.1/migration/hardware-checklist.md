# PhotoPainter 实机验收清单

本清单需要连接真实设备执行。主机测试、编译和静态核对不能代替这些项目；本次实施不烧录、不擦除、不调用付费生图接口。

| 项目 | 操作与预期 |
| --- | --- |
| 已有配置 | 保留 NVS 更新，原模式、Wi-Fi、设备身份继续有效；不要 erase-flash |
| 首次启动 | 无模式记录进入基础模式；原有模式 1/2/3/4 按原值分派 |
| 切换模式 | KEY 长按进入模式选择，短按切换，长按确认；重启进入所选模式 |
| 模式提示音 | 四段提示音从无损压缩数据恢复播放；连续切换/重复播报无杂音，PSRAM 缓存分配正常 |
| 基础相册 | BOOT 短按下一张后休眠；定时及 BOOT 唤醒切图，KEY 唤醒不切图；BOOT 长按休眠 |
| 电量页 | BOOT 双击显示电池状态；同时检查 AI 模式 BOOT 原有配网单击回调与双击扫描的相互影响 |
| 网络 AP | 热点 esp_network，密码 1234567890；用原 SD 网页上传，首字节模式 0/1 协议不变 |
| 网络 STA | 先在 AI 模式配网；上传后选择 STA，重启连接原路由器；失败时按原 BOOT 操作回到 AP |
| 网络休眠 | 检查无连接约 30 秒休眠、30 秒定时唤醒、断开及 BOOT 长按休眠、KEY 唤醒 |
| AI 对话 | 你好小智唤醒；录音、播报、中断、重新联网和设备端 AEC；输入输出仍为 24 kHz |
| AI 按键 | KEY 短按在 idle 唤醒；BOOT 单击重启进入配网；BOOT 长按停止会话，不能改为整机休眠 |
| 启动天气 | 启动和普通对话无天气请求、无天气刷屏；说“刷新天气”才请求；网络错误后旧画面保留，恢复后可再次请求 |
| 图片工具 | 指定序号、获取数量、开始/退出倒序轮播、设置分钟/小时周期；默认一分钟，重启不保存轮播周期 |
| 生图 | 用有效自有配置发起一次请求：Seedream 5.0 Flash、1280×720 JPEG；生成后拉伸到 800×480 并六色抖动，覆盖 sys_ai.jpg |
| 生图失败 | HTTP 400/超时不显示成功图片；恢复网络/参数后能重试；“已提交”不代表显示完成 |
| 温湿度 | 语音查询 SHTC3，返回设备实测温湿度，与天气 API 区分 |
| 绿灯 | GPIO42 低电平亮；任务支持 1/2/3/4 闪，200 ms（当前业务没有直接触发这些次数事件）；刷新连续 100 ms 闪；停止后灭 |
| 红灯 | GPIO45 低电平亮；原传输连续闪顺序保留，停止后亮；错误 400 ms 五闪后灭；listening/speaking 亮、回 idle 灭 |
| 显示与电源 | SD 卡四线读取、横竖图、六色电子纸完整刷新、AXP2101 充电状态和深睡功耗 |

SD 卡仍使用原配套 02_SDCARD 的目录结构。Flash 内的语音模型资源与 SD 卡图片资源不同，升级语音组件时须使用本次生成的匹配资源。

- [ ] AI 模式首次配网后切换网络模式 STA，确认使用新 SSID/密码连接。
- [ ] 在已有旧驱动凭据的设备上重新配网，确认网络模式优先使用新版保存信息；默认网络不可达仍符合原超时逻辑。

## 图片刷新分离验收

- [ ] 新固件启动并重新建立 AI 会话后，“刷新图片”在意图不明时先询问，不触发天气 HTTP。
- [ ] 显示 SD 图片后说“重新刷当前图片”，画面不变、不联网天气、不生图，轮播停止。
- [ ] 本次开机未显示画面时请求重刷，提示先显示图片，无空白刷屏。
- [ ] “刷新天气”仍正常获取天气；“生成一张动漫图”仍走生图；异步提交回复不宣称已完成。
- [ ] 天气画面重刷不更新天气数据；重刷时遇到轮播/其他显示事件的行为符合当前画面定义。
